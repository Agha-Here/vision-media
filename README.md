# Vision Media

Portfolio site for Vision Media, a multimedia agency (video editing and graphic design).

## What is in this repo

- `index.html` — the full site as a single self-contained file (all images and assets inlined). Open it in any browser, or serve it with GitHub Pages.
- This repo is a backup of the live site, which is built and edited in Muse. The live site is at https://muse.ai/s/vision-media-rxi6jx0oxa2xb8l/FaHjmlJeq4OAQYrfiuKSf4RzkNdl8iXZ5CMspZ0AiR0

## Placeholders

Stats, testimonials, work samples, client logos, and contact details in this build are placeholders and will be replaced with real ones over time.

## Updating

Edits made in Muse are re-exported and pushed here. Edits made directly to `index.html` here do not automatically update the Muse live link.
